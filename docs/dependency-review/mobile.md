# Mobile dependency review

Reviewed 2026-10-02 UTC using live npm version/time/peer/engine metadata, upstream release notes and changelogs, a batched GitHub review of recent open issues for each upstream repository, and a separate package-specific Expo issue search. Issue reports are evidence of possible problems, not proof that Orca is affected. The package security scan includes the full resolved mobile lockfile; GitHub Advisory Database entries were also checked for every external direct package.

The selection preserves the 4,320-minute release-age gate, Expo SDK 55, RN 0.83, React 19.2, and the paired Reanimated 4.3/Worklets 0.8 runtime. Native SDK jumps require a coordinated migration and device evidence, not independent package bumps. All tests/build scripts run with `ORCA_BACKGROUND_LAUNCH=1`; no app windows were launched.
