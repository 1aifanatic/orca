# Cloud and docs dependency review

Reviewed 2026-10-02 UTC. Version selection used the registry snapshot and a 72-hour minimum release age at approximately 06:08 UTC. The tables compare **actual original lockfile versions** with the final selected versions; a manifest range alone is not an upgrade. Latest versions are registry observations, not recommendations to adopt every major.

The review covered all 33 unique external direct package names in `cloud/` and `docs/site/`, their package-manager pins, docs security overrides, cloud runtime baselines, and Terraform provider locks. Primary release notes, changelogs, advisories, and a bounded sample of recently updated upstream issues were checked. An issue search is not proof that a release has no defects. Internal `workspace:*` packages retain their existing source and wire contracts.

## Selected changes and release policy

Both isolated projects use pnpm **10.34.6**, replacing 10.24.0. The [10.34.6 release](https://github.com/pnpm/pnpm/releases/tag/v10.34.6) includes self-update resolution/TLS hardening and a Windows Node archive extraction dependency security fix. Latest pnpm observed was 12.8.1; isolated projects retain the maintained major-10 workflow rather than changing package-manager semantics with the app upgrades. Installations used `corepack pnpm@10.34.6`, avoiding the initially installed global pnpm 12.0.0.

`cloud/pnpm-workspace.yaml` now sets `minimumReleaseAge: 4320`. Docs uses the equivalent one-line `.npmrc`, because its documented `--ignore-workspace` installation ignores workspace YAML and pnpm 10 does not read this setting from `package.json.pnpm`. The docs `.gitignore` now permits this credential-free project policy file; credentials belong in user-level npm configuration. There are **no release-age exceptions**.
