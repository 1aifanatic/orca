# Desktop dependency review

Reviewed on 2026-10-01 PDT / 2026-10-02 UTC. Before versions come from the committed project lockfile, not stale node_modules or npm dist-tags. Four agents divide mobile, cloud/docs, desktop platform/toolchain and desktop app libraries. The matrix below enumerates every root direct declaration; companion reports explain platform, mobile and cloud decisions.

Registry package versions, publish dates, engines and peers were fetched directly. For app libraries, the first 25 most recently updated open GitHub issues per repository were inspected, then relevant regressions and chosen release notes were read. That bounded issue sweep and registry audit cannot establish absence of unknown vulnerabilities. The 72-hour age gate remains in every workspace, with no new exceptions. Stale root exemptions were removed.

## Chosen app changes and deferrals

- **@anthropic-ai/claude-agent-sdk**: Update: faster startup, smaller SDK, control requests stop leaking after query closure, fixes background-turn stdin closure. Keep user-resolved CLI and all eight optional binary exclusions. [Release](https://github.com/anthropics/claude-agent-sdk-typescript/releases/tag/v0.3.284). In-process MCP record-schema issue [454](https://github.com/anthropics/claude-agent-sdk-typescript/issues/454) concerns tool/createSdkMcpServer, which Orca does not use; older user CLIs need existing contract tests.
- **@linear/sdk**: Update: ESM-only release halves installed SDK size and updates API schema; Node 24 supports require(ESM), so CJS callers remain supported. [Migration](https://github.com/linear/linear/releases/tag/%40linear%2Fsdk%4097.0.0). Typecheck, Linear contracts and built CJS loading are required.
- **agent-browser**: Hold: [2032](https://github.com/vercel-labs/agent-browser/issues/2032) reports replaying commands after a lost response; [1964](https://github.com/vercel-labs/agent-browser/issues/1964) reproduces blank offscreen screenshots on 0.38.1. Newest 0.38.2 is below release-age gate. Native helper packaging/CDP compatibility needs a separate migration.
- **i18next**: Update: [26.4.0 hierarchy cache](https://github.com/i18next/i18next/blob/master/CHANGELOG.md) removes repeated Intl locale work; 26.4.2 fixes nesting replacement loops, and TS7 peer support is explicit. Orca uses a static fallback language; does not mutate cache-sensitive language options.
- **react-i18next**: Already latest, retain with updated i18next; registry peer range and translation tests cover compatibility.
- **posthog-node**: Hold: mature 5.54.1 changes feature flag evaluation/cache metadata; Orca uses capture/flush/shutdown rather than these APIs. Latest 5.55.0 is below release-age gate. [Changelog](https://github.com/PostHog/posthog-js/blob/main/packages/node/CHANGELOG.md).
- **dompurify**: Update direct and Monaco override together: [GHSA-p98j-92pf-mc4p](https://github.com/cure53/DOMPurify/security/advisories/GHSA-p98j-92pf-mc4p) fixed by 3.4.16. All direct/Monaco/Mermaid copies must resolve patched version.
- **ws**: Update: [8.22.0](https://github.com/websockets/ws/releases/tag/8.22.0) fixes close() with invalid arguments incorrectly entering CLOSING; new protocols option is additive. Cover relay and cloud framing/reconnect tests.
- **zod**: Already latest; retain 4.6.5. Cloud intentionally stays on Zod 3 to preserve contract/schema behavior.
- **zustand**: Update: [5.0.15](https://github.com/pmndrs/zustand/releases/tag/v5.0.15) fixes storage-clear versus pending rehydration and devtools path-with-spaces handling; same release used in mobile.
- **sonner**: Hold, now exact pin: [786](https://github.com/emilkowalski/sonner/issues/786) reproduces indefinitely replayed stale toasts after remount on 2.0.8, absent on 2.0.7.
- **radix-ui**: Update mature patch set: focus pressed tab before state change; RSC regressions corrected in 1.6.7. [Focus fix](https://github.com/radix-ui/primitives/pull/4060). [4097](https://github.com/radix-ui/primitives/issues/4097) concerns SWC eliminating a side-effect IIFE; Orca uses Rolldown rather than SWC, but production keyboard behavior needs rendered verification.
- **emoji-picker-react**: Update: [4.22.2](https://github.com/ealush/emoji-picker-react/releases/tag/4.22.2) fixes structural config comparisons/reference observer triggers and reactive category updates; 4.22.3 is mature maintenance.
- **react-colorful**: Hold: 5.8 adds Shadow DOM style injection, unused by Orca. 5.7 already includes end-of-change callbacks. [Release](https://github.com/omgovich/react-colorful/releases/tag/v5.8.0).
- **monaco-editor**: Hold: 0.56 reorganizes ESM paths/removes worker APIs; Orca imports private editor/language modules and cancellation/disposal internals. [Changelog](https://github.com/microsoft/monaco-editor/blob/main/CHANGELOG.md), [wrapper type break](https://github.com/suren-atoyan/monaco-react/issues/771). Security dependency fixed independently via DOMPurify override.

[Changelog](https://github.com/KaTeX/KaTeX/blob/main/CHANGELOG.md).
